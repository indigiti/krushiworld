# APMC Pune Data Engine v1.4.0 — Editorial Dark Market Theme

The public market dashboard and system console now use a dark-first editorial visual system inspired by the supplied Lexicon MILE v4 reference: near-black surfaces, oversized type, thin rules and a sharp lime accent. Collector, scheduler, fallback, storage and API behavior remain unchanged from v1.3.3.

See `RELEASE_NOTES_v1.4.0.md` for the visual scope and `SERVER_SCHEDULER.md` for server refresh setup.
