# KrushiPulse 1.9 — Pretty URLs and multilayer application

## Public URL contract

With Cloudways DigiOps deployed at /krushiworld (change the prefix for portable installs):

| Purpose | Pretty URL |
|---|---|
| Marathi home | /krushiworld/mr/ |
| English home | /krushiworld/en/ |
| Marathi mandi directory | /krushiworld/mr/mandis/ |
| English mandi directory | /krushiworld/en/mandis/ |
| One verified mandi | /krushiworld/en/mandis/main-market-yard/ |
| Another mandi | /krushiworld/mr/mandis/manjari/ |
| Public API directory | /krushiworld/api/v1/markets |
| Public API one mandi | /krushiworld/api/v1/mandis/main-market-yard/rates |
| Latest snapshot | /krushiworld/api/v1/latest |
| Admin | /krushiworld/admin/ |

Stable market identifiers are taken from verified Pune/AGMARKNET source IDs. No guessed market pages are created. Unknown market paths return HTTP 404. Market pages without a published report are noindex and clearly identify that rates might not exist. Market pages reuse the established accessible KrushiPulse dashboard and select the requested market after directory loading.

Legacy routes, such as /krushiworld/index.php?api=latest, /krushiworld/?view=admin, /krushiworld/?lang=mr, the original /api/markets, and the historical api.php adapter, remain compatible. Existing browser preferences and cached rate files are preserved.

## Multilayer structure

    public/index.php                     HTTP front controller (small entrypoint)
    public/.htaccess                    Apache pretty URL rewrites
    app/Http/RouteResolver.php          strict prefix-aware route resolution
    app/Http/PublicApiController.php    legacy + versioned API responses, HTTP validation
    app/Application/MarketDirectoryService.php  combine Pune and national directories
    app/Application/MarketRatesService.php      select verified records per market
    app/RateRepository.php              Pune read-only JSON repository
    app/NationalMarketRepository.php    national read-only JSON repository
    app/DataNormalizer.php              commodity/market normalization
    app/views/home.php                  localized page presentation
    collector/                          independent scheduled Python collectors
    public/build/                       deployed front-end assets only

Dependencies flow HTTP -> application -> repositories -> storage. Request handlers do not import data from external websites. Data ingestion runs on the server cron, with preserved last-good snapshots.

## SEO and routes

- All canonical and alternate language URLs use /en/ or /mr/ with the same market ID; switching language preserves the selected mandi route.
- XML sitemap includes both language variants for source-reported markets, and excludes empty no-report pages. No bogus live-price metadata is published.
- Legacy links continue to return the page rather than suddenly breaking.
- Market-price table and saved-market panel now contain shareable permalinks.
- OpenAPI describes the new public v1 mandi endpoint alongside legacy aliases.
- Requests with encoded path separators, traversal attempts, unknown market IDs or unrecognized route shapes fail closed.
- Query-string view/API selectors work only on the legacy entry URL to avoid route confusion.

## Cloudways and consent-based GPS

Public files deploy to public_html/krushiworld/, private source to private_html/krushiworld/. Neither config nor storage is published in the public directory. All new Http/Application service classes are in the private artifact. The .htaccess rules run on Apache; the PHP local router in tools/php-dev-router.php is **test-only** and never shipped to public web roots.

Permissions-Policy now allows geolocation=(self) so a farmer can explicitly opt in to the nearest-mandi finder. GPS is not requested automatically. HTTPS and browser permission are still required; coordinates remain in browser memory only.

## Verification

CI runs PHP syntax checks, a pure routing/service contract test, Python collector tests, JavaScript syntax and commodity-emoji tests, PHP split-root HTTP smoke tests (including real pretty routes, canonical links and 404), and independent DigiOps artifact verification.

Commands:

    php apmc-rates/tests/test_pretty_routes.php
    python -m unittest discover -s apmc-rates/tests -p 'test_*.py' -v
    node --test apmc-rates/tests/commodity-icons.test.cjs

A successful release artifact is deployable but not proof that DigiOps installed it. After deployment verify that Cloudways rewrite is enabled, the /krushiworld/en/mandis/ page loads under HTTPS, the route's canonical URL is correct, and the selected mandi loads published rates. National AGMARKNET coverage still needs its own server API key and a successful import.
