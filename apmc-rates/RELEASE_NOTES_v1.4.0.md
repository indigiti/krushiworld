# APMC Pune Data Engine v1.4.0 — Editorial Dark Market Theme

## Visual redesign

- New dark-first public dashboard inspired by the visual language of the supplied Lexicon MILE v4 reference.
- Near-black market canvas, warm off-white typography, acid-lime status accent and thin editorial rules.
- Oversized hero typography with a clearer live-market hierarchy.
- Flat, square data surfaces replace the previous rounded/elevated dashboard cards.
- Market tape becomes a high-contrast live information strip.
- Commodity cards, rate table, language controls, system controls and data-guide surfaces share one coherent visual system.
- Admin console receives the same design language without altering collector or recovery behavior.
- Dark mode is the default for first-time visitors; an existing saved theme preference is still honored.
- Responsive behavior, English/Marathi support, accessibility focus states, reduced-motion support, server scheduler, page fallback and all data APIs remain intact.

## Scope

This release changes presentation only. The v1.3.3 server-driven collection/failover logic and data model are unchanged.
